# Product & Customer Revenue Analysis using SQL

## Project Overview
This academic project focuses on analyzing product, order, and customer data using SQL. The goal is to explore revenue patterns, identify data quality issues, and generate useful business insights from the data.

## Project Objectives
- Identify data quality issues and inconsistencies in the dataset.
- Analyze product revenue and identify the top-performing products.
- Examine customer purchasing patterns.
- Categorize products by price using `CASE WHEN`.
- Develop business recommendations based on the analysis.

## Tools & Technologies

- Relational database queries

## Skills Demonstrated
